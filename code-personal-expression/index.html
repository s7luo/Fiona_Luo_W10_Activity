Example 01

Choose what to measure

FaceMesh estimates landmarks. FaceFeatures.extract() turns selected points into six ratios. We chose these features; the model did not name them.

  1. Start the webcam, or select synthetic input.
  2. Move closer, farther away, then slightly sideways.
  3. Compare the preview with the ratios below it.
  4. Perform a few comfortable expressions. Which ratios change?

No examples are saved in this view. Landmark tracking is not custom training.
